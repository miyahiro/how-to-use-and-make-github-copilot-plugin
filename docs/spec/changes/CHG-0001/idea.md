## 前提・制約

- 確認済み: 当初案の対象環境は VS Code 1.145.3。
- 確認済み: 公式ガイドでは Plugin の User／Workspace 単位の導入、グローバル／Workspace 単位の有効化が案内されている。有効化の範囲は導入場所と別に扱われる。
- 公式資料上の仕様: Copilot harness では `.github/copilot/settings.json` がリポジトリの Plugin と marketplace の既定値を提供する。利用者の実機確認ではこの設定が Copilot CLI と VS Code の Copilot Chat で有効にならなかったとの報告があり、CLI で追加した Plugin は両方で利用できたとのこと。記事執筆時に対象バージョンと適用範囲を再確認する（詳細は [note.md](note.md)）。
- 確認済み: sdd の例では Git リポジトリ内に Plugin と marketplace 定義を置いている。公開手順の詳細は要件定義で対象を決める。
- 制約: harness やバージョンにより利用できる機能が異なるため、記事執筆時に対象バージョンで再確認する。
