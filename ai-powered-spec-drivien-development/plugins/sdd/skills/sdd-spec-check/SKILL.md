# 検査

入力: 任意の変更 ID（`CHG-0001` 形式）、機械で読むなら `--json`。前の工程の承認は不要。

1. このスキルの `SKILL.md` と同じフォルダーにある `scripts/check.mjs` の絶対パスを確かめる。
2. workspace のルートで、`node <このフォルダー>/scripts/check.mjs [変更ID] [--json]` を実行する。検査するのは実行したフォルダーなので、別のフォルダーで実行しない。
3. エラーと警告を、ファイル・行・内容のまま示す。変更 ID を付けたら、案件の要約（題名・規模・工程・状態・ブランチ・期限の来た質問・承認と再承認・タスクの件数・次の作業）を使う。
4. 終了コードが 1 ならエラーがある、0 なら警告だけかなし。2 は使い方の誤りなので、引数を直してやり直す。
5. ファイルを変えない。エラーの修正は、呼び出した手順か窓口が扱う。

停止: Node.js がない（20 以上が必要）、スクリプトが見つからない。

出力: エラーと警告の一覧、変更 ID を付けたときは案件の要約。
